# Randopedia Modern

Site web moderne pour le Club Randopedia - Escapade du Sud marocain.

## Stack

- HTML5
- Tailwind CSS (via CDN)
- Google Fonts (Playfair Display + Inter)

## Preview

Ouvrir `index.html` dans un navigateur.

## Déploiement

Options recommandées :
- **GitHub Pages** : Gratuit, juste activer dans les settings
- **Netlify** : Drag & drop du dossier
- **Vercel** : Import depuis GitHub

## Structure

```
├── index.html      # Page principale
└── README.md       # Ce fichier
```

## Personnalisation

Les couleurs sont configurées dans le `tailwind.config` inline :
- `sand` : #E8DCC4 (fond clair)
- `desert` : #C4A77D (accents dorés)
- `terracotta` : #C75B39 (CTA, badges)
- `night` : #1A1A2E (texte sombre)
